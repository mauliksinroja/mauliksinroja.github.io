How I build

01 · Discovery

You see it before I build it

I bring clickable prototypes to discovery meetings. A requirement that surfaces in week zero costs a conversation; the same one in week four costs a sprint.

02 · Architecture

AI-assisted, human-accountable

Claude, Codex and Gemini speed up review and boilerplate. BLoC keeps that output strict and reviewable. Every line that ships is code I can explain and own.

03 · Release

Critical fixes in minutes, not days

Production apps ship with Shorebird code push, so a critical bug gets patched without waiting on a store review cycle.
